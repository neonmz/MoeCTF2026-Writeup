# [代号：碎片风暴](https://ctf.xidian.edu.cn/games/37/challenges?challenge=1287)
##### 分值：150pts

## 题目描述：
### 原文：
服务器突然涌入了大量的并发请求！而且每个请求体里，都只带了一小段零碎的字符串。
运维人员抓包后发现，这些字符串似乎是某个重要机密（Flag）的碎片。它们没有序号、没有偏移量，顺序完全是乱的。
你能写一个高性能的服务，接住这些高并发请求，并把完整的 Flag 拼凑出来吗？

### 前置知识

请学习 Python环境配置与基础语法 与 Flask基础知识，并了解ssh、scp工具的使用方式后尝试解答本题

附件提供本题可能涉及到的算法知识供参考

### 你的任务：

- SSH 登录题目提供的服务器。题目环境开放了一个ssh端口，用户名与密码都是moectf
- 编写一个监听 3000 端口的 HTTP 服务。
- 接收机器人发送的 POST 请求，Body 为 plain text。
- 收集足够多的碎片后，将它们拼接成完整的 Flag，并输出到控制台。

注意：机器人发送请求的频率较高，请合理设计代码逻辑防止容器被卡死

服务器没有安装 Vim、Nano 等编辑器，建议在本地编写代码后使用 scp 上传。

from http.server import HTTPServer, BaseHTTPRequestHandler

class MyHandler(BaseHTTPRequestHandler):
    def do_POST(self):
        content_length = int(self.headers.get('Content-Length', 0))
        body = self.rfile.read(content_length)
        
        print(body.decode('utf-8', errors='ignore'))
        
        self.send_response(204)
        self.end_headers()

    def log_message(self, format, *args):
        pass

if __name__ == '__main__':
    server = HTTPServer(('localhost', 3000), MyHandler)
        server.serve_forever()
